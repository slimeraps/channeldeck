Install

ChannelDeck runs on Macs with Apple Silicon (M1 or newer) and a recent macOS.

1. Download

Get ChannelDeck-<version>-arm64.dmg from the latest release on GitHub. Each release lists its SHA-256 if you want to check the download.

2. Install

Open the .dmg and drag ChannelDeck to Applications.

3. Open it the first time

ChannelDeck is signed on the Mac that built it but isn't notarized by Apple, so macOS blocks a downloaded copy the first time you open it:

  1. Open ChannelDeck once and close the warning.
  2. Go to System Settings → Privacy & Security, scroll down to the ChannelDeck message, click Open Anyway and confirm.

On macOS 15 and later, right-click → Open no longer skips this step. You only do it once per version.

When macOS asks about "ChannelDeck Safe Storage" in your Keychain, click Always Allow. That's where ChannelDeck keeps the key that encrypts your sign-ins.

4. Set it up

The Set up ChannelDeck checklist at the top of the Queue takes you through each step. The setup guide explains the Google and Twitch parts in detail.

Updating

Quit ChannelDeck (from the menu bar icon or with ⌘Q), drag the new version to Applications and replace the old one. Your channels, posts, clips and settings stay as they are. Uploads that were interrupted continue on the next launch.

Uninstalling

Remove your channels in ChannelDeck first so their Google and Twitch access is revoked. Then quit it, delete it from Applications, and delete the folders listed on Your data.

Build it yourself

You can also build the app from source with Node.js. See Develop.
