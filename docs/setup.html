Setup

ChannelDeck talks to YouTube and Twitch with your own free developer apps, so your quota and your sign-ins belong to you. Each part takes a few minutes and you only do it once.

  • Connect Google and your YouTube channels
  • Connect Twitch
  • The setup checklist

Connect Google and your YouTube channels

  1. In the Google Cloud Console, create a project and enable YouTube Data API v3 and YouTube Analytics API (the second is only for the Analytics page).
  2. Under Google Auth Platform → Branding, fill in the app name and your email for User support email and Developer contact. Google won't let you publish without these links (leave the logo empty):
    • Application home page: https://slimeraps.github.io/channeldeck/
    • Application privacy policy link: https://slimeraps.github.io/channeldeck/privacy.html
    • Authorized domains: slimeraps.github.io
  3. Under Audience, set the user type to External and click Publish app so the status says In production.
  4. Under Clients, create an OAuth client ID of type Desktop app and download its JSON file.
  5. In ChannelDeck, click Import… in the setup checklist (or Settings → Google and Twitch apps) and pick the downloaded client_secret_….json.
  6. Click Add channel, once per channel. For a Brand Account channel, pick it in Google's chooser.

Why "In production"? In Testing mode, Google signs you out of every channel after 7 days. You don't need Google's verification for personal use: on the warning screen, click Advanced → Go to ChannelDeck.

Sign-in opens your browser and comes back to ChannelDeck on a temporary 127.0.0.1 address, so there are no redirect URLs to set up. The client file is copied into ChannelDeck's own folder with owner-only permissions.

Connect Twitch

  1. In the Twitch developer console, click Register Your Application.
  2. Add the OAuth Redirect URL http://localhost:17563/twitch/callback, set Client Type to Confidential, and create it.
  3. Open Manage, click New Secret, and paste the Client ID and Client Secret into ChannelDeck (Channels → Twitch accounts).
  4. Click Connect Twitch, choose whether you're the broadcaster or an editor of the channel, and pick how far back to load clips.

Without a secret, ChannelDeck uses Twitch's device-code sign-in instead, but those sign-ins expire after 30 days.

Clips are saved to ~/Movies/ChannelDeck/Clips/<channel>/<year>/<year-month>/ (you can change the folder in Settings), named like 2026-11-12_204512_<clip id>_<title>_landscape.mp4 so Finder sorts them oldest to newest. A thumbnail and a .json file with the clip's details sit next to each video.

The setup checklist

The Set up ChannelDeck card at the top of the Queue ticks off each step as you finish it: Google client file, consent screen in production, a YouTube channel, the Twitch app, a Twitch channel, and your clip folder. You can hide it and bring it back from Settings.

Try it safely first

Dry Run is in Settings → Uploads. While it's on, ChannelDeck shows exactly what it would send to YouTube and moves posts through their statuses without uploading anything.
