Develop

ChannelDeck's source code is public on GitHub. You can run it from source, build your own copy, and read how it's put together.

Run from source

You need a Mac with Apple Silicon, Node.js 22 or newer (LTS recommended), and the Xcode Command Line Tools for git (xcode-select --install). 

git clone https://github.com/slimeraps/channeldeck.git
cd channeldeck
npm install
npm run dev

Running from source and the installed app share the same database, so only one can be open at a time.

Commands

Command What it does
npm run dev Run the app with hot reload
npm run typecheck TypeScript checks for every part of the app
npm run lint ESLint
npm run format Prettier (format:check to verify)
npm test Vitest, run on Electron's own Node
npm run db:generate Generate a SQL migration from the schema
npm run dist Build the macOS .dmg into release/

How it's built

Stack: Electron, TypeScript (strict), React, electron-vite, Tailwind CSS with shadcn/ui, TanStack Query, Zustand, SQLite (better-sqlite3 with Drizzle), Google's official YouTube client, Luxon, zod, and Vitest with msw for tests.

  • src/main: the database, the Google and Twitch clients, the background job runner, video tools (ffmpeg, ffprobe) and the app's API to the window.
  • src/preload: the only bridge between the window and the rest of the app.
  • src/renderer: the React interface.
  • src/shared: types, validation and constants used by both sides.

Scheduling, time slots, clip picking, templates, quota and error handling are pure functions with their own tests. The plan the app was built from is in PLAN.md, and the working notes are in CLAUDE.md.

Security

  • The window is sandboxed with no Node access. It can only call a fixed, typed set of functions, and every call's input is validated.
  • Local videos reach the window only through a restricted cdmedia:// address that serves files from the clip and render folders or files your posts use.
  • Sign-in tokens and secrets are encrypted with the macOS Keychain, kept out of logs and backups, and never committed.

Build the app

npm run dist

This makes release/ChannelDeck-<version>-arm64.dmg (Apple Silicon, ad-hoc signed, not notarized) and the app itself in release/mac-arm64/.

To check a build without touching your data, run its self-test. In a throwaway folder it applies every database migration, makes a test video with the bundled ffmpeg, reads it with ffprobe, renders a vertical version, and runs a Dry Run upload. It exits 0 when everything works: 

CHANNELDECK_SELF_TEST="$(mktemp -d)" release/mac-arm64/ChannelDeck.app/Contents/MacOS/ChannelDeck
